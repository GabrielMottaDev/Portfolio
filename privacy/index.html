Política de Privacidade

Esta política vale para as ferramentas pessoais publicadas sob o domínio gabrielmotta.dev, incluindo o JobPilot.

O JobPilot é uma ferramenta de uso pessoal, operada exclusivamente pelo dono deste domínio, para organizar a própria busca de emprego. Ele não é oferecido a outras pessoas.

Com a autorização do titular da conta, a ferramenta acessa o Gmail e o Google Agenda da própria conta para ler e enviar e-mails e criar eventos. Esses dados ficam armazenados apenas no computador do titular, não são vendidos e não são compartilhados com terceiros.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Contato: contato@gabrielmotta.dev

Privacy Policy

JobPilot is a personal tool operated solely by the owner of this domain to manage their own job search. It is not offered to anyone else.

With the account owner's authorization, it accesses that account's Gmail and Google Calendar to read and send email and create events. This data is stored only on the owner's computer, is never sold and is never shared with third parties.

Access can be revoked at any time at myaccount.google.com/permissions. Contact: contato@gabrielmotta.dev
